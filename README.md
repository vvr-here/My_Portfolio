# Vineet — Personal Portfolio

A modern, responsive, single-page personal portfolio built with **HTML5, CSS3, and Vanilla JavaScript**. Designed to showcase my technical skills, projects, certifications, and professional background to recruiters and potential collaborators.

## 🚀 Getting Started

### Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

Alternatively, run a local development server:

```bash
python -m http.server 8000
```

Visit `http://localhost:8000` in your browser.

## ✏️ Customization

All portfolio content can be updated directly in the source files.

- **Personal Information:** Update your name, introduction, education and contact details in `index.html`.
- **Skills:** Add or remove skills from the Skills section.
- **Projects:** Duplicate an existing project card and update its information.
- **Certifications:** Update certification names, issuers and dates.
- **Profile Photo:** Add your image to `assets/images/` and reference it in the HTML.
- **Resume:** Place your PDF inside a `resume/` folder and add a download link.
- **Colors & Themes:** Customize CSS variables in `css/style.css`.

# Vineet — Personal Portfolio

A modern, responsive, single-page personal portfolio built with **HTML5, CSS3, and Vanilla JavaScript**. Designed to showcase my technical skills, projects, certifications, and professional background to recruiters and potential collaborators.


## 📁 Project Structure

```text
MyPortfolio/
│
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   └── images/
│
└── README.md
```

## 🛠️ Technologies & Features

**Technologies**
- HTML5
- CSS3
- Vanilla JavaScript

**Features**
- Responsive design for mobile, tablet and desktop.
- Dark and light theme with saved preferences.
- Interactive mobile navigation.
- Smooth scrolling and scroll animations.
- Accessible navigation and keyboard support.
- Reduced-motion support.
- Lightweight design with no external dependencies.

NOTE 01 · DNS

Names become routes

DNS maps a human-readable domain to an IP address, helping a browser find the server it needs.

NOTE 02 · CDN

Closer can be faster

A CDN can serve cached content from an edge location nearer to a visitor, reducing the trip to the origin.
